# M10: Package and polish

Working method: `CLAUDE.md`. Roadmap: section 5, M10. Spec: 14 (packaging and first run), 11
(UX rules, accessibility). Findings from `docs/spikes/m0-packaging.md`.

## Features, in build order

1. **Build** (`packaging/pyinstaller.spec`, `packaging/build_dmg.sh`, `make build`): web build,
   `uv sync --locked`, PyInstaller windowed onedir with web/dist and resources, dev tools
   excluded, native packages collected (onnxruntime, pillow-heif, PyObjC Vision, AVFoundation,
   UserNotifications), Info.plist (bundle id `local.sift.app`, macOS 13.0, removable-volume
   text, version), ad-hoc signing, a .dmg with an Applications link (`hdiutil`; `create-dmg`
   when installed). arm64 only.
2. **Starter teaching** (owner request): when `SIFT_TEACHING` (default `local/teaching.json`,
   git-ignored) exists at build time, it is bundled as `resources/teaching/starter.json`; on a
   fresh install (no labels, never loaded) the app loads it once, so the classifier and the
   suggestions start with the owner's teaching. Never committed.
3. **Crash dialog**: an uncaught exception (main or any thread) writes
   `logs/crash-DATE.txt`; the window shows a dialog with Open logs (the next launch too, when
   the app died before it could show one).
4. **About and removal**: version in Settings, General (About); README with install
   (right-click Open), first run, removal (drag to Bin, delete Application Support and Caches;
   backups untouched), and the developer workflow. THIRD_PARTY.md generated from the installed
   packages' licence metadata (`scripts/third_party.py`).
5. **Accessibility and UX pass** (spec 11 UX rules): thumbnails have ARIA labels (file name and
   top reason), visible focus everywhere, red buttons never take default focus, waits over 2 s
   say what is happening, contrast AA in both appearances.

## Exit

`make build` produces Sift.app and Sift.dmg from a clean checkout; the frozen app starts
headless, serves the UI, migrates a database and stops cleanly; checks green. Owner: install
from the dmg on the Mac (right-click Open) and open the window once.

## Assumptions

- M1. ffmpeg is not bundled: video frames come from AVFoundation (M6), so nothing calls it.
- M2. The dmg is made with `hdiutil` (built into macOS) when `create-dmg` is not installed; no
  background image (the README carries the right-click Open note).
- M3. Starter teaching carries labels by content hash, so it helps on the owner's own pictures
  (a reinstall, the same phone); it does not carry pictures or embeddings.
- M4. The crash dialog uses the web UI (a `crash` event and a crash report check at startup)
  rather than a native alert, so it works from any thread.
