# Sift M0 Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A uv-managed Python 3.14 app that opens a native window showing a React shell, which reads `/api/status` and stays connected to `/api/events`, with config, SQLite migrations, logging, single-instance lock, tests and CI in place.

**Architecture:** `sift.app.main` takes the instance lock, builds an `AppContext` (paths, config, DB, event bus, token), serves FastAPI with uvicorn on a pre-bound `127.0.0.1` socket in a thread, and opens a pywebview window at `/?t=TOKEN`. The React app (Vite build in `web/dist`) is served by the same server. All later milestones plug routers and engines into this context.

**Tech Stack:** uv, CPython 3.14.7, FastAPI, uvicorn, pydantic v2, tomlkit, pywebview, sqlite3; React 18.3.1, TypeScript, Vite, Tailwind v4, TanStack Query, Zustand, react-router, vitest, Playwright (WebKit); pytest, hypothesis, ruff, mypy; GitHub Actions (macOS arm64).

**Spec:** the maintainer's private product spec. It is kept out of this repository; section numbers in this plan refer to it, and every requirement a task needs is restated in the task itself.

## Global Constraints

- Python is uv-managed CPython **3.14** (`.python-version` = `3.14`, `requires-python = ">=3.14,<3.15"`); always run Python through `uv run`. Node **24 LTS** (`web/.nvmrc`).
- "Pin every version": `uv.lock` and `web/package-lock.json` committed; npm installs use `--save-exact`; React exactly `18.3.1`.
- Server binds `127.0.0.1` only; rejects other Host values; requires the per-launch token in `X-Sift-Token`; sets no CORS headers. `?token=` is accepted only on `GET /api/events` and `GET /api/media/*` (spec 12).
- The token never appears in any log: uvicorn's access log is off, and Sift's own request logging records method and path without the query string.
- Error shape for every API error: `{"code": str, "message": str, "detail": any | null}`. No stack traces in any response or UI text.
- SQLite: `journal_mode = WAL`, `foreign_keys = ON`, `synchronous = NORMAL`. Timestamps are Unix seconds UTC.
- Migrations are numbered SQL files (`0001_init.sql`, …). The app refuses to start on a database newer than itself, and copies the DB before migrating.
- Config path `~/Library/Application Support/Sift/config.toml`; unknown keys warned about; bad values fall back to the default.
- App Support folder `~/Library/Application Support/Sift/` (state.db, config.toml, logs/, models/, platform-tools/, backups/); cache `~/Library/Caches/Sift/thumbs/`. Tests never touch the real folders (`SIFT_HOME` override).
- Window 1280 x 800 default, 1000 x 680 minimum. Sidebar 200 px: Backup, Cleanup, Quarantine, Logs, Settings. System font; follows macOS light/dark.
- No network access at runtime (I8); M0 makes no outbound calls.
- mypy strict on `sift.core.*`, `sift.backup.*`, `sift.cleanup.*`.
- Commits are authored by the owner only, through the repo-local git config. No `Co-Authored-By` or other AI attribution trailer in any commit message. Never change the global git config.

## Review Focus

1. **Token where headers are impossible.** `EventSource` and `<img>` cannot send `X-Sift-Token`; the window must still get live events. Expected: `?token=` works for `GET /api/events` (and later `/api/media/*`) only, and is refused for every other endpoint. Because the token rides in URLs (`/?t=`, `?token=`), it must never reach a log file or stderr. → Task 6 `test_token_in_query_not_accepted_for_status`, Task 8 `test_live_server_serves_status_and_sse` and `test_token_never_logged`.
2. **A hand-edited or broken `config.toml`.** Expected: a bad value or unknown key never stops the app; a file that isn't valid TOML is set aside (not deleted) and defaults load; the warnings reach the UI via `/api/status`. → Task 3 tests, Task 6 `test_status_reports_config_warnings`.
3. **Database from a newer Sift, damaged, or a migration that fails halfway.** Expected: plain-words refusal, never a half-applied schema, a copy taken before any migration. → Task 4 tests, Task 8 `test_main_refuses_newer_database`.
4. **The UI stops reading events** (window reloaded, Mac asleep, slow WebKit). Expected: publishers on worker threads never block; the dead subscriber is removed. → Task 5 `test_publish_never_blocks_on_stalled_subscriber`, Task 7 `test_stream_unsubscribes_on_disconnect`, Task 8 subscriber-count assertion.
5. **Second launch, or launch after a crash.** Expected: a second instance exits with "Sift is already running."; a lock left by a killed process does not block the next launch. → Task 8 lock tests.

**Interfaces:**
- Produces:
  ```python
  class Config(BaseModel):  # sections: phone, backup, analysis, scoring, cleanup, slate, browse, apps, health
      ...
  def load_config(path: Path) -> tuple[Config, list[str]]: ...   # (config, human-readable warnings)
  def save_config(cfg: Config, path: Path) -> None: ...           # atomic; keeps user comments
  ```
  One pydantic model per section with **every key and default from spec section 13** (all three TOML blocks, including "Settings added by backup sets, adoption and confirmation"), field names identical to the TOML keys. Notable values: `phone.adb_server_port = 5037`; `backup.adopt_mode = "hash"`; `backup.confirmation_valid_days = 30`; `cleanup.delete_reminder_days = 0`. **`backup.roots` no longer exists**; it is replaced by:
  ```python
  class BackupSet(BaseModel):
      name: str                                   # non-empty, unique within backup.sets
      paths: list[str]                            # non-empty; each starts with "/sdcard/"
      exclude: list[str] = []
      enabled: bool
      deletable: bool
      adopt_mode: Literal["hash", "fast"] = "hash"   # "fast" is reserved: load warns, M3 treats it as hash
  # BackupConfig.sets: list[BackupSet], default = DEFAULT_SETS
  ```
  `DEFAULT_SETS` (spec 7 Backup sets table, in this order): Camera `["/sdcard/DCIM"]` exclude `["/sdcard/DCIM/Screenshots"]` on/deletable; Screenshots `["/sdcard/DCIM/Screenshots", "/sdcard/Pictures/Screenshots"]` on/deletable; Pictures and Movies `["/sdcard/Pictures", "/sdcard/Movies"]` exclude `["/sdcard/Pictures/Screenshots"]` on/deletable (the exclude stops one file from belonging to two sets); WhatsApp media `["/sdcard/Android/media/com.whatsapp/WhatsApp/Media"]` on/deletable; WhatsApp Business `["/sdcard/Android/media/com.whatsapp.w4b/WhatsApp Business/Media"]` off/deletable; Documents `["/sdcard/Documents"]` on/**not** deletable; Downloads `["/sdcard/Download"]` off/deletable. The spec's "Custom" row is not a default entry (it has no paths). Custom sets are added by the owner or come from a legacy `roots` key.
  Set loading rules: each `[[backup.sets]]` entry is validated on its own; an invalid entry or a duplicate name is dropped with a warning naming it (`backup.sets[2] ("Foo"): …`). A legacy `[backup] roots = [...]` with no `sets` becomes one set `{name: "Custom", paths: roots, enabled: true, deletable: false, adopt_mode: "hash"}`, with the warning `"backup.roots is replaced by backup.sets; loaded as one Custom set"`. If both are present, `sets` wins and `roots` is ignored with a warning. `adopt_mode = "fast"` (top level or per set) warns `"…adopt_mode fast is not built yet; hash is used"`. `save_config` writes sets as a TOML array of tables (`[[backup.sets]]`) and never writes `roots`.
  `cleanup.never_delete` default additionally contains `/sdcard/Android/obb`, `/sdcard/Android/media/com.whatsapp/WhatsApp/Databases`, `/sdcard/Android/media/com.whatsapp/WhatsApp/Backups`, `/sdcard/Android/media/com.whatsapp.w4b/WhatsApp Business/Databases`, `/sdcard/Android/media/com.whatsapp.w4b/WhatsApp Business/Backups` (spec 13 last paragraph).
  Constraints: ports 1024–65535; `parallel_reads_*` 1–6; `*_pct` 0–100; day counts ≥ 0 (`quarantine_days` ≥ 1); cosines/thresholds 0–1; `layout` `Literal["mirror","by_date"]`; `ocr_provider` `Literal["auto","vision","tesseract"]`; `disposition_default` `Literal["archive","quarantine"]`; `required_destinations` non-empty list of `Literal["mac","ssd"]`.

**Interfaces:**
- Produces:
  ```python
  class DatabaseCorruptError(Exception): ...
  class DatabaseTooNewError(Exception): ...
  class MigrationError(Exception): ...

  class Database:
      def __init__(self, path: Path) -> None: ...
      def open(self) -> None: ...                      # pragmas + PRAGMA quick_check; DatabaseCorruptError on failure
      def read(self) -> ContextManager[sqlite3.Connection]: ...   # thread-local connection
      def tx(self) -> ContextManager[sqlite3.Connection]: ...     # BEGIN IMMEDIATE; commit / rollback
      def close(self) -> None: ...

  @dataclass(frozen=True)
  class Migration: version: int; name: str; sql: str
  def bundled_migrations() -> list[Migration]: ...     # importlib.resources: sift/resources/migrations/NNNN_*.sql
  def schema_version(db: Database) -> int: ...         # 0 for an empty database
  def apply_migrations(db: Database, backup_dir: Path,
                       migrations: Sequence[Migration] | None = None) -> int: ...  # returns version
  ```
  `tests/conftest.py`: fixture `db(paths) -> Database` (opened and migrated, closed on teardown).
- Decisions: connections use `isolation_level=None` (explicit transactions). `tx()` holds a process-wide `threading.Lock` and retries `BEGIN IMMEDIATE` on `database is locked` up to 5 times (50, 100, 200, 400, 800 ms). Pragmas run in `open()` for every new connection, never in migration files. Each migration runs as one `executescript` of `BEGIN IMMEDIATE; <sql>; INSERT INTO schema_migration …; COMMIT;`, with `rollback()` on error, then `MigrationError("Migration NNNN failed: …")`. Before applying pending migrations to a DB at version ≥ 1, copy it with `sqlite3.Connection.backup` to `backup_dir/state-v<old>-<ts>.db`.
- `0001_init.sql` = every `CREATE TABLE` / `CREATE INDEX` from spec section 5, verbatim, without the three `PRAGMA` lines.

def test_tx_rolls_back_on_exception(db):
    with pytest.raises(RuntimeError), db.tx() as c:
        c.execute("INSERT INTO setting VALUES ('a', '1')")
        raise RuntimeError
    with db.read() as c:
        assert c.execute("SELECT count(*) FROM setting").fetchone()[0] == 0

def test_concurrent_writers(db):
    def work(n):
        for i in range(50):
            with db.tx() as c:
                c.execute("INSERT INTO setting VALUES (?, '1')", (f"{n}-{i}",))
    threads = [threading.Thread(target=work, args=(n,)) for n in range(8)]
    for t in threads: t.start()
    for t in threads: t.join()
    with db.read() as c:
        assert c.execute("SELECT count(*) FROM setting").fetchone()[0] == 400

Event ids are a global increasing counter starting at 1.
