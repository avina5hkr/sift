## Design records

Sift was built in milestones (M0 to M14), each planned, built, tested and reviewed in turn. These
records explain why the code is the way it is. They are kept as written at the time, so details
may have changed since; the code and the documents above are current.

- [superpowers/plans/2026-11-05-sift-roadmap.md](superpowers/plans/2026-11-05-sift-roadmap.md):
  the roadmap and the invariants (I1, I3 and others) that the code refers to.
- [superpowers/plans/](superpowers/plans/): one plan per milestone, each with its assumptions and
  outcome, and the [hardening pass](superpowers/plans/2026-11-15-hardening.md) after an external
  review of backup, clean-up, duplicates and learning.
- [spikes/](spikes/): short experiments done before a milestone (packaging, the adb protocol,
  backup and quit behaviour, analysis speed, OCR), with measurements.
